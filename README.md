# NEURAL — Interactive 3D Digital System & Neural Architecture

**NEURAL** is an immersive futuristic WebGL/Three.js interactive experience representing a living AI and software architecture. Explore interconnected nodes across Artificial Intelligence, APIs, Backend Systems, Databases, Automation, Security, and Applications.

![NEURAL System Architecture](https://raw.githubusercontent.com/Booster-ux/Neural/main/public/preview.png)

## 🌐 Live Experience Highlights

- **3D Neural WebGL Universe**: Built with React Three Fiber, Three.js, and custom shaders.
- **Central AI Core**: Gyroscopic concentric gimbal rings, pulsing corona, and live telemetry diagnostics.
- **7 Major Interactive Nodes**:
  - `AI` (LLMs, Autonomous Agents, RAG, Automation)
  - `BACKEND` (Node.js, Express, REST APIs, Auth, Webhooks)
  - `DATABASE` (PostgreSQL, Supabase, RLS, Real-time streams)
  - `APIs` (REST, Gateways, OAuth, Third-Party Integrations)
  - `AUTOMATION` (Event-driven workflows, BullMQ, Job queues)
  - `SECURITY` (Zero-Trust, RBAC, Row Level Security, Policies)
  - `APPLICATIONS` (React, TypeScript, Interactive UI/UX)
- **Live Cybernetic Data Flow**: Dynamic particle streams traveling continuously between interrelated nodes.
- **Layered Architecture View**: 3D multi-tier stacked system (User → Frontend → API Mesh → Backend → Data Layer → External Services) with moving data packets.
- **System Blueprint Map**: 2D topological map with instant 3D camera navigation.
- **Web Audio API Synthesizer**: Pure synthesized sci-fi soundscapes, ambient sub-drones, hover blips, and warp transitions without external audio files.
- **Command Palette (`Ctrl+K` / `Cmd+K`)**: Rapid keyboard search and node teleportation.
- **Developer Easter Eggs**: Root access terminal and hidden autonomous node logs.

## 🛠️ Technology Stack

- **Framework**: React 18 & TypeScript
- **Bundler**: Vite
- **3D Engine**: Three.js & `@react-three/fiber`
- **3D Helpers**: `@react-three/drei`
- **Animation**: GSAP & Three.js Frame Interpolation
- **Icons**: Lucide React
- **Sound**: Web Audio API Synthesizer

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/Booster-ux/Neural.git

# Navigate to project directory
cd Neural

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
